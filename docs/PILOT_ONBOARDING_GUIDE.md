# LocalWheels — Pilot Customer Onboarding Guide
**Version:** 1.0 | **Phase:** 25 (Production Operations)

---

## Overview

This guide covers onboarding the 3 pilot customers onto LocalWheels v1.0 in production. The process takes approximately 2–3 hours per company including the onboarding call.

**3 Pilot Companies:**
1. Sunrise Logistics Pvt Ltd (Mumbai) — SL001
2. Northern Star Transport Co (Delhi) — NS001
3. South Express Cargo Services (Bengaluru) — SE001

## Onboarding Call Agenda (60 minutes)

### Part 1: Login & Navigation (10 min)
1. Share URL + credentials
2. Walk through the dashboard overview
3. Show branch selector (bottom-left)
4. Show role-based navigation (admin sees everything)

### Part 2: Core Workflow Demo (20 min)
Walk through the primary workflow live:
1. **CRM** → Leads → Create a lead (their actual customer name)
2. **Leads** → Convert to Opportunity → Set value + stage
3. **Quotes** → Generate quote → Set pickup/destination/weight
4. **Shipments** → Book shipment → Note the LR# auto-generated
5. **Control Tower** → See shipment appear in live ops
6. **POD** → Verify POD created automatically
7. **Finance → Invoices** → Invoice auto-generated

### Part 3: AI Features (10 min)
1. **Executive Cockpit** → Show the daily AI snapshot
2. **Finance Copilot** → Ask: "What is my cash flow status?"
3. **Revenue Forecast** → Show the AI revenue projection
4. **Warehouse AI** → Show inventory recommendations

### Part 4: Branch & User Setup (10 min)
1. **Settings → Users** → Show how to add staff users
2. **Settings → Branches** → Walk through branch configuration
3. Assign vehicles/drivers to branches

### Part 5: Q&A & Next Steps (10 min)
1. Take questions
2. Agree on "first live shipment" target date
3. Share support contact and escalation path
4. Schedule 1-week check-in call

## Adding Real Data (During/After Onboarding Call)

After the pilot company is comfortable with the system, help them import their real data:

### Add Real Customers
```
Settings → Master Data → Customers → Import CSV
# Or manually: CRM → Customers → + New Customer
```

### Add Real Vehicles
```
Fleet → Vehicles → + New Vehicle
# Required: Registration Number, Type, Model, Capacity
```

### Add Real Drivers
```
Fleet → Drivers → + New Driver
# Required: Name, Phone, License Number, License Expiry
```

### Import Existing Shipment History (Optional)
If the company wants historical data, use a custom import via `mongoimport` or the bulk-create API.

## Common Onboarding Questions

**Q: Can we change the branch names?**  
A: Yes — Settings → Branches → Edit.

**Q: How do we add more users?**  
A: Settings → Users → Invite User. Assign role + branch.

**Q: The AI response is slow on first load. Is that normal?**  
A: Yes — first load calls Anthropic AI (~2-4s). Subsequent calls within the cache window (5 min for Executive Cockpit, 1 hour for Forecast) return instantly.

**Q: Can we import our existing customers as a CSV?**  
A: CSV bulk import is on the v2.0 roadmap. For now, use the + New Customer form (takes ~2 min per customer).

**Q: How do we reset a user password?**  
A: Settings → Users → [user] → Reset Password.

**Q: What happens if the AI is unavailable?**  
A: The platform continues operating normally. AI features show either cached data or a basic text fallback. No business-critical functions depend on AI.
