# Quick Start Guide — Warehouse Staff
**LocalWheels v1.0** | 5-minute setup

---

## Step 1: Log In
- URL: https://app.localwheels.com
- Username: `wh_staff1` (or assigned username)
- Password: As provided by Admin

---

## Step 2: Receive Inbound Goods
1. **Warehouse → Inbound Center** → New Inbound
2. Scan or enter the LR/barcode of arriving cargo
3. Enter: Quantity received, condition (Good / Damaged / Shortage)
4. Select storage location → Click **Confirm Receipt**
5. System updates inventory automatically

---

## Step 3: Check Inventory
- **Warehouse → Inventory** → Shows real-time stock
- Filter by: SKU, location, status
- Low stock items are highlighted in orange

---

## Step 4: Pick for Outbound
1. **Warehouse → Outbound Center** → Open pick list
2. Pick items as per list
3. Scan each item to confirm pick
4. Move to dispatch dock → **Warehouse → Dock Management**

---

## Step 5: Handle Warehouse Tasks
- **Warehouse → Tasks** → Your assigned tasks appear here
- Types: QC check, stock count, relocation, cleaning
- Mark each task: In Progress → Complete

---

## Daily Checklist
- [ ] Complete pending inbound receipts from overnight arrivals
- [ ] Process any QC tasks
- [ ] Pick and pack outbound orders scheduled for today
- [ ] Update task list with completed items

---
