# Quick Start Guide — Dispatcher
**LocalWheels v1.0** | 5-minute setup

---

## Step 1: Log In
- URL: https://app.localwheels.com
- Username: `dispatcher1` (or assigned username)
- Password: As provided by Admin

---

## Step 2: Book an LR (Lorry Receipt)
1. **Entries → LR Booking** → New LR
2. Fill: From Branch, To Branch, Sender, Receiver, Items, Weight
3. Click **Save** → LR Number auto-assigned (e.g., `LR-HO-2026-00001`)
4. Print LR or share via WhatsApp

---

## Step 3: Create a Trip
1. **Dispatch → Trip Management** → New Trip
2. Select: Vehicle, Driver, Route
3. Add LRs to the trip (search by LR number)
4. Click **Dispatch** → Driver receives notification on mobile app

---

## Step 4: Track Live
- **Control Tower → Live Operations** → See all active trips on map
- Click any vehicle → Real-time location, ETA, status

---

## Step 5: Mark Delivery
- Driver marks delivery via mobile app → Status auto-updates to "Delivered"
- POD (Proof of Delivery) uploaded by driver → Shipment closes

---

## Daily Checklist
- [ ] Review pending LRs (Entries → LR Booking → Pending)
- [ ] Assign vehicles to ready trips
- [ ] Check Control Tower for exceptions (delayed, breakdown)
- [ ] Confirm previous day deliveries closed

---
