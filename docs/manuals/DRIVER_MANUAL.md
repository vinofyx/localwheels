# LocalWheels Platform — Driver Manual (Mobile App)
Version 1.0 | Phase 19.7 | Production Release

## 1. Getting Started
- Download the **LocalWheels Driver App** (Android/iOS)
- Login with your credentials provided by your dispatcher
- Allow Location and Camera permissions when prompted

## 2. Daily Workflow

### Start of Day
1. Open app → Login
2. Tap **Today's Trips** to see your assigned trips
3. Tap a trip to view route details and consignment list

### Starting a Trip
1. Select trip → Tap **Start Trip**
2. GPS tracking activates automatically
3. Your dispatcher can see your live location

### Delivery & POD
1. On arrival at delivery point, tap **Deliver**
2. Collect recipient signature (tap **Sign Here**)
3. Take a photo of the delivery receipt
4. Tap **Submit POD** — syncs when online

### Offline Mode
- All actions are saved locally if you're offline
- App automatically syncs when you reconnect
- Never lose a POD — offline queue is persistent

### Incident Reporting
1. If an accident or delay occurs, tap **Report Incident**
2. Select type: Accident / Breakdown / Delay / Cargo Damage
3. Add photo and description
4. Submit — dispatcher is notified immediately

### End of Day
1. Complete all deliveries
2. Tap **End Trip** when returning to depot
3. Check your **Performance** tab for daily score

## 3. Key Screens
| Screen | Purpose |
|--------|---------|
| Today's Trips | View all trips assigned for today |
| Digital POD | Capture delivery proof (signature + photo) |
| Voice Commands | Hands-free operation while driving |
| Driver Documents | View your license, fitness, insurance docs |
| Performance | Your KPIs: on-time rate, safety score, fuel efficiency |

## 4. Safety
- Never use the app while driving — use Voice Commands instead
- Say "Hey LocalWheels, mark delivered" to update status hands-free
- Report all incidents immediately — there is no penalty for honest reporting
